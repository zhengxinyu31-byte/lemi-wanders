# Lemi's Diary · 章鱼仔的旅行手账

> 一个以「故事」为主线、偏旅行的互动产品：把城市变成一条条可漫游的「故事线」。
> 首个样本：**巴黎 ×《艾米莉在巴黎》**。深度参考开源项目 [storymap](https://github.com/cuizicheng1024/storymap)。

本仓库沉淀「章鱼仔的旅行手账」从需求、调研到原型 demo 的**已确定成果**。

---

## 一、当前已确定的方向

- **主客体反转**：storymap 的「人物 × 一生时间轴」→ 本产品的「故事线 × 路线行程动线」。
- **常规模式为唯一主体**：昼夜模式已移除；游戏模式移入《游戏模式后续规划》。
- **首页 = 世界地图入口**；追问卡等已裁撤。
- **真实感三件套**：真实地图（MapLibre + CARTO + 真实经纬度）+ 真实照片（Wikimedia）+ 真实动线。
- **设计北极星（最新对齐）**：「一部可交互的巴黎微纪录片」——Web 宽屏，整体重构，镜头是主角、叙事是旁白、观看有节奏。
- **三合一融合心法**：一号的「骨」（真地图/动线/工程）+ 三号的「魂」（读完点亮/克制留白/hook→fact→end）+ 二号的「温度」（Lemi 对话入口/名人第一人称导游/解锁徽章）。
