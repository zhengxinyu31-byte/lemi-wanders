# 16 旅行人格 × 16 条巴黎故事线 · 选线框架

> 人格体系来源：内部《旅行人格测试》飞书文档（12 题 / 4 维度 / 各 0–6 分，维度 ≥4 为高、<4 为低）。
> 本文档是把"人格"映射到"故事线选 POI"的算法说明书。人格名称、英文代号、文案均沿用原测试，不改写。

## 1. 四个维度（决定选点口味）

| 维度 | 高 | 低 |
|---|---|---|
| `culture` 文化 | 爱历史/名人/典故/博物馆/有来历的战利品 | 爱风光/烟火/出片/轻松，不做功课 |
| `planning` 规划 | 要精确攻略、预约、备选方案、打卡必去 | 走到哪算哪、灵感带路、下雨也是隐藏支线 |
| `social` 社交 | 爱搭话/热闹/认识本地人/一群人 | 一个人/少数密友、安静、不想被打扰 |
| `spending` 消费 | 为舒服体验付费、加钱省时、来都来了 | 该省省、硬排队、找平替、预算花在交通 |

2⁴ = 16 种组合，每种一条专属线路。

## 3. 维度 → POI 属性的匹配规则（装配线路时用）

给每个 POI 打上 4 个维度的"适配分"（0/1/2），选线时按人格的高低组合加权：

- **culture 高** → 优先 `艺术/文学/地标历史/建筑城市/名人墓园` 类，且 hook 要有典故；**culture 低** → 优先 `美食/河与桥景观/生活方式/公园/出片/夜生活`，hook 要轻松不用预习。
- **planning 高** → 线路给"精确顺序 + 预约/联票/闭馆日/备选雨天方案"，POI 可含需要提前抢票的（凡尔赛、地下墓穴、卢浮宫时段票）；**planning 低** → 线路给"松散片区 + 随到随走 + 免费弹性点"，不塞硬预约。
- **social 高** → 优先有"人"的场景：市集、酒吧、大桌食堂、cabaret、能和摊主/邻座互动的点；**social 低** → 优先可独处：清晨包场机位、小众馆、花园、墓地、河岸长椅。
- **spending 高** → 可放米其林、SPA、头等舱游船、塔楼、名店；**spending 低** → 以免费/低价为主，并显式给"平替"（如：花神贵 → 双叟或随便一家本地 bistro；登塔贵 → 老佛爷免费屋顶）。

## 4. 核心 POI 复用原则

- 16 条线**允许大量复用同一批核心 POI**（铁塔、卢浮宫、圣母院、塞纳河岸、花神、老佛爷等"巴黎必到"会反复出现），差异来自：
  1. **进同一个点的"打开方式"不同**（卢浮宫：NERD 慢慢看三宝与策展 / TIME 高效冲三宝拍照 / LORD 私享导览 / BUDD 只在花园和金字塔静静坐）；
  2. **顺序与节奏不同**（高规划紧凑 vs 低规划松散）；
  3. **每个人格替换 2–4 个"人格专属点"**（GOAT 的米其林、BEE 的跳蚤市场、REST 的 hammam、WIND 的肖蒙公园等）。
- 每条线约 **6–8 站**，其中核心枢纽 POI 占 4–5、人格专属点占 2–3。

## 5. 内容缺口与补搜（不硬凑原则）

现有 80+ POI 偏"高文化"，为 8 个低文化人格补 4 类体验型 POI（专门补搜，编号 09–12）：
- 09 夜生活娱乐（秀/酒吧/游船派对/夜景）
- 10 奢华治愈（米其林/SPA/hammam/下午茶）
- 11 公园户外（免费公园/屋顶/河岸/最佳机位）
- 12 市集购物出片（跳蚤/百货/古着/高奢橱窗）

> 原则：发现某人格在现有库里找不到贴合点时，去搜新 POI/事件，不用高文化点硬凑。

## 6. 每条线的统一交付结构

```
线路名（人格代号 · 一句人格标签）
- 适合的他/她：1-2 句画像
- 节奏：紧凑/松散；步行强度；预算档
- 站点（6-8）：每站给"为这个人格定制的打开方式 + hook + 1 条专属 tips"
- 预约/省钱提示（高规划线给全套，低规划线给最少必要）
- 暗线：走完才懂的那句
```
