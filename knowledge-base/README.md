# Lemi 巴黎知识库

> 「章鱼仔的旅行手账」的内容底座：一批**真实可去、有故事、可被不同故事线反复串联**的巴黎 POI，
> 以及它们与人物、作品、事件、彼此之间的关联网络。
>
> 调性：**旅游为主，略带文艺，娱乐轻松向**。不做学术专著，但每条事实都要经得起"较真的游客"追问。

---

## 0. 怎么用这份知识库

- `README.md`（本文件）：入选标准、分类、数据模型、关联模型、信源规则。
- `storylines/*.md`：按故事线组织的人工可读长文（每个 POI 完整条目 + hook + 轶事 + tips + 信源）。
- `data/pois.json`：机器可读的 POI 主数据（坐标/分类/标签/关联/置信度），供 demo/前端直接消费。
- `data/entities.json`：人物 / 作品 / 事件实体（供 tooltip、关系图谱、名人导游）。
- `data/storylines.json`：故事线定义（包含哪些站、顺序、暗线）。
- `sources.md`：全部信源汇总与可靠性说明。

## 1. POI 入选标准（Inclusion Criteria）

一个地点要进库，**必须同时满足"硬门槛"，再按"加分项"排序取舍**。

### 1.1 硬门槛（不满足直接淘汰）

1. **真实存在且可到访**：2025-2026 年仍对外开放（或有明确的外部可看性，如广场/建筑外观/桥）。已永久关闭、拆除、普通游客无法到达的不收。
2. **真实坐标可定位**：有 WGS84 `[lng,lat]` 或精确到门牌号的可地理编码地址。
3. **有"非来不可"的叙事钩子**：能用一句轻松的话讲出"它为什么有趣"——和某个人、某部作品、某桩轶事、某个时代强绑定。纯功能性地点（普通地铁站、连锁超市）不收。
4. **事实可交叉验证**：关键事实（是什么/年代/与谁有关）有 **≥2 个相互独立的可信信源**；只有单一来源、且来源是自媒体/旅游聚合站的，先放"待核区"，不进正式库。
5. **安全合规**：不引导进入危险区域、私人场所或明显违法的行为（地下墓穴非开放段不鼓励）。

### 1.2 加分项（用于在候选里排序）

- **跨线复用度高**：一个点能同时挂在 ≥2 条故事线上（如花神咖啡馆 = 文学线 × 艾米莉线），优先收录——它们是"关联网络"的枢纽。
- **步行/地理可串联**：能与同线其它点在半日/一日内顺走，形成真实动线，而不是散点。
- **情绪反差/画面感强**：有"没想到吧"的反转、有经典画面、有适合拍照/发呆的场景。
- **有实用 tips 可给**：预约方式、最佳时间、避坑点——对"真要去"的人有价值。
- **时代层累感**：一个地点身上叠了多个时代（如西岱岛），叙事厚度大。

### 1.3 明确不收 / 谨慎收

- 纯网红打卡但无真实故事支撑的点（可在"待核区"观察）。
- 口碑严重翻车、对游客不友好的点。
- 都市传说：**可以收，但必须显式标注 `[传说]`**，不得当作史实讲（如"伏尔泰一天 40 杯咖啡"）。
- 影视虚构设定：现实与剧情分开写（剧中餐厅名 vs 现实真店）。

## 2. 分类体系（Taxonomy）

### 2.1 主题分类（一个 POI 可有多个标签，多选）

| 分类 | 含义 | 典型 |
|---|---|---|
| `影视` | 电影/剧集取景地 | Place de l'Estrapade、双磨坊咖啡馆 |
| `文学` | 作家足迹/文学事件/书店出版 | 花神咖啡馆、莎士比亚书店、雨果故居 |
| `艺术` | 博物馆/画廊/艺术家空间/名作藏地 | 卢浮宫、奥赛、橘园、洗衣船 |
| `地标历史` | 皇室/革命/拿破仑/世博会的纪念碑 | 铁塔、凯旋门、凡尔赛、协和广场 |
| `建筑城市` | 城市格局、建筑风格、特色空间 | 奥斯曼大道、拱廊街、玛黑区、孚日广场 |
| `美食` | 咖啡/甜点/烘焙/市集/老餐馆 | Chartier、红孩子市场、Berthillon |
| `河与桥` | 塞纳河、岛屿、桥梁、运河 | 新桥、艺术桥、西岱岛、圣马丁运河 |
| `名人墓园` | 凭吊/猎奇/名人安息地 | 拉雪兹神父公墓、蒙帕纳斯公墓 |
| `小众猎奇` | 反主流/地下/隐秘角落 | 地下墓穴、旧书摊、皇宫艺术柱 |
| `生活方式` | 时尚/购物/本地日常 | 香奈儿康朋街、老佛爷、旧书摊 |

### 2.2 叙事类型（内容生产用，沿用 hook→fact→end）

- `scene` 场景：在作品/影视里出现过的画面。
- `anecdote` 轶事：有温度/反转的真实小故事。
- `work` 名作：与某作品的创作/出版/收藏直接相关。
- `history` 历史：改变城市/时代走向的大事件现场。

### 2.3 空间分类（动线规划用）

- 右岸 / 左岸 / 两座岛 / 东北蒙马特 / 东郊拉雪兹 / 西南近郊凡尔赛。
- 标注所属 **arrondissement（区）**，用于做"按区探索"。

## 3. 数据模型

### 3.1 POI 条目（`data/pois.json` 元素）

```json
{
  "id": "estrapade",
  "name_zh": "埃斯特拉帕德广场",
  "name_fr": "Place de l'Estrapade",
  "coords": [2.3494, 48.8436],
  "arrondissement": 5,
  "address": "Place de l'Estrapade, 75005 Paris",
  "categories": ["影视", "建筑城市"],
  "sceneTypes": ["scene", "anecdote"],
  "storylines": ["emily-paris"],
  "hook": "艾米莉每天推开窗看到的喷泉广场，真实住户却曾联名投诉游客太多。",
  "facts": [
    {"text": "…", "confidence": "verified"},
    {"text": "…", "confidence": "legend"}
  ],
  "entities": ["emily-in-paris", "netflix"],
  "tips": ["居民楼，拍照保持安静", "喷泉和面包店都在同一广场"],
  "visit": {"type": "outdoor", "fee": "免费", "booking": "无需"},
  "image_query": "Place de l'Estrapade Paris",
  "sources": ["https://…", "https://…"],
  "confidence": "high"
}
```

### 3.2 置信度（confidence）

| 值 | 含义 | 呈现规则 |
|---|---|---|
| `high` | ≥2 独立可信源一致 | 正常讲 |
| `medium` | 2 源但有出入 / 来源偏软 | 可讲，用"据说/一般认为"软化 |
| `low` | 单源或无法证实 | 进待核区，不上正式故事线 |
| `legend` | 都市传说/文学掌故 | 明确以"传说"口吻讲，不当真 |

### 3.3 事实标注（每条 fact 自带）

`verified`（史实，可考）/ `legend`（传说掌故）/ `disputed`（有争议，给分歧）/ `fictional`（影视/小说虚构设定）。

## 4. 关联模型（让点能被多条故事线串起来）

这是知识库的灵魂：**不是一堆孤立景点，而是一张网。**

### 4.1 三类关联

1. **POI ↔ 实体（人/作品/事件）**：多对多。
   - 例：花神咖啡馆 ↔ 萨特、波伏娃、《现代》杂志；又 ↔《艾米莉在巴黎》。
2. **POI ↔ POI**：带关系类型。
   - `步行可达`（同动线）、`隔河相望`、`同一人物线`、`同一时代`、`因果`（如被小说拯救：雨果小说 → 圣母院修复）。
3. **故事线 ↔ 故事线**：通过**共享枢纽 POI** 相交。
   - 例：先贤祠 = 大时代线 × 文学线 × 艾米莉线；花神 = 文学 × 艾米莉；奥赛 = 艺术 × 大时代。

### 4.2 七条候选故事线（首版）

| id | 故事线 | 情绪 | 代表枢纽 |
|---|---|---|---|
| `emily-paris` | 艾米莉在巴黎 × 拉丁区 | 轻松浪漫、追剧打卡 | Estrapade、花神、歌剧院 |
| `amelie-montmartre` | 天使爱美丽 × 蒙马特 | 古灵精怪、坡地漫游 | 双磨坊、爱墙、圣心堂 |
| `left-bank-literature` | 左岸文学（存在主义×迷失一代） | 文艺、思想的咖啡味 | 花神、双叟、莎士比亚书店 |
| `art-impressionism` | 艺术殿堂 × 印象派 | 从宫殿到破房子 | 卢浮宫、奥赛、洗衣船 |
| `seine-bridges` | 塞纳河 × 桥 × 两座岛 | 慢、水、恋爱 | 圣母院、新桥、艺术桥 |
| `grand-epochs` | 大时代地标（皇室/革命/世博） | 宏大、权力更替 | 铁塔、凯旋门、凡尔赛 |
| `food-life` | 用嘴认识巴黎 | 最轻松、烟火气 | Chartier、红孩子市场 |
| `offbeat-fashion` | 时尚建筑 × 小众猎奇 | 体面与 B 面 | 康朋街、拉雪兹、拱廊街 |

> 首条样板 = `emily-paris`（一城一线 6-7 站，与 MVP 对齐）。其余作为内容储备，支持用户"从一个枢纽点跳进另一条线"。

### 4.3 暗线（每条线末尾揭示）

每条故事线有一句"走完才懂"的暗线（见各线文档结尾），把散落的点升华成一个主题。这是三号半成品最打动人的设计，予以保留。

## 5. 信源与可靠性规则

### 5.1 信源分级

1. **一级（权威）**：景点/机构**官网**、UNESCO、政府/博物馆官方、Wikidata。
2. **二级（可信）**：Wikipedia（多语种互证）、BBC/NYT/Guardian/Le Figaro/Le Monde 等主流媒体、Smithsonian、Lonely Planet/Time Out/Eater 等专业媒体。
3. **三级（辅助）**：成熟的取景地专题博客、Atlas Obscura（猎奇线索）——**只能作辅助，不能作为唯一来源**。
4. **不采信**：无署名营销号、内容农场、纯 UGC 点评（除非用于"现状/口碑"参考）。

### 5.2 交叉验证规则

- 入库 POI 的关键事实：**≥2 个独立域名信源**，且至少 1 个为一级或二级。
- **最易错的三类**，强制人工复核：① 年份/数字（建立/高度/距离/价格）；② 名作藏在哪家馆；③ "最古老/第一/最好"类断言。
- 价格/营业时间等易变信息：标注"以 2025-2026 资料为准，出行前复核官网"。
- 门牌号：两个独立源一致才写死，否则只写街区。

### 5.3 诚实原则

- 史实、传说、剧情、争议**分开标注**，不把掌故当正史、不把剧情当现实。
- 信息缺口宁可不写，也不编。无法证实的进"待核区"。
