## 二、ちよ散歩 完整闭环拆解（最贴近我们的样板）

宇野千代（うのちよ / Uno Chiyo，1897-1996，山口县岩国市出身女作家、编辑、和服设计师）的文学散步项目，2026秋配合NHK晨间剧「ブラッサム」放送，是"文学地图+线下完整闭环"的教科书。

**1. 路线设计——8条主题散步路线**（[chiyosanpo.jp](https://chiyosanpo.jp/)）
按情绪/主题切分，而非单纯地理：①名所巡礼 ②千代的美味放学路 ③千代的初恋咖啡巡礼 ④樱花与和服的散步 ⑤《おはん》余韵文学散步 ⑥怀想生家、墓前追思 ⑦父亲故乡·高森 ⑧《幸福的言葉》寻访。
——**启示：主题化、情感化切分，一个地点可归多条线**。这正对应我们"多条故事线"的设计。

**2. 三合一收集活动「いち！に！さんぽ！」**（同源官网正文）
- **いち！数字集章拉力**：用 App「furari」扫码/GPS。期间令和8年9/19–令和9年2/28（约5个月）。**15个点位**（"幸福的言葉"等）。**分档抽奖**：5点→QUOカードPay 300円(100名)、10点→文学套装+手帕(10名)、15点全集→岩国特产+书籍(5名)。
- **に！Instagram投稿活动**：透过眼镜/眼镜型道具拍"岩国的幸福"，加 #めがね越しの岩国 + 关注官号。特赏 Christian Dior 眼镜框(1名)。——**UGC传播**。
- **さんぽ！明信片收集**：巡访4处设施（宇野千代生家、本家松がね、岩国学校教育资料馆、いわくに交流テラスMiraido），**集齐的明信片拼成一整幅插画**。——**拼图式完成物**，纯收集驱动、无抽奖。

**3. 盖章点设在哪 / 集章后给什么**
- 数字章点位 = 千代生平文学地标（生家、墓所教蓮寺、"幸福的言葉"留言板、作品舞台等）。
- 之后给：分档实物奖（QUOカードPay、文学套装、手帕、特产、书籍），以及明信片拼图完成物。

**4. 主题商品**：千代设计的和服、手帕、餐垫等小物（生家内销售）、陶器（本家松がね"樱花"主题展）、文学套装。传统食物复活（いが餅——因千代"想吃故乡いが餅"而复活）。

**5. 电动自行车接入——「ちよクル」**（[Yahoo新闻/tysテレビ山口](https://news.yahoo.co.jp/articles/9b5876eb5d5f17157b37e326a3a73db1aee895e8)；[岩国观光振兴课](https://kankou.iwakuni-city.net/岩国ちよ散歩に「ちよクル」（レンタサイクル）.html)）
- **岩国工业高校学生有志发案**，被市观光事业采用；名称=宇野千代+cycle。
- 电动辅助自行车，巡游锦带桥周边观光点与宇野千代ゆかりの地。
- 配合另一套「錦帯ペダル」租赁（[くるとんWEB](https://crouton.co.jp/story/670/)）：本家松がね出借，电动辅助自行车3台，3小时800円/1日2000円，含住宿客半价券；注意自行车不能过锦带桥。
- 另有连接锦带桥·生家·教育资料馆的**免费接驳巴士**。

**闭环全景**：主题路线（8条）→ 数字集章App（15点，分档奖）→ UGC(Instagram) + 拼图明信片 → 实物周边（和服/手帕/食物）→ 电动自行车/接驳巴士解决移动 → 全部锚定"名誉市民作家+晨间剧IP"的情感叙事。

> **对我们最直接的抄作业点**：①主题化路线而非地理罗列；②分档奖励而非集满才给；③一个"拼图完成物"作为纯收集终点；④UGC分享做传播引擎。

## 三、集章 / 御朱印 / 护照机制的共性

1. **都有一本"专属容器"**：御朱印帳、护照本、集章台纸/App。容器本身即身份与仪式感，且"未填满的空页"制造持续张力（暗合蔡加尼克）。
2. **每一枚都带"到访证明"**：御朱印含参拜日期、护照章含点名+日期。"我真的去过"是核心价值。
3. **稀缺性来自"现场+不可预期"**：御朱印现场手写、季节限定；护照有特别版章。**"完成前不知长什么样"** 是御朱印的上瘾核心（[tsunagujapan](https://www.tsunagujapan.com/complete-beginner-s-guide-to-collecting-goshuin-japan-s-beautiful-temple-stamps/)）。
4. **点位数量分两种定位**：护照(400+)/御朱印(全国无限)→"终生慢收集"，不逼集满；主题集章拉力(如ちよ 15点、五馆文学巡礼)→短期可完成，配分档奖。
5. **数字化路径已成熟**：QRコード扫码 或 GPS定位（[BALANCe](https://balance.bz/magazine/category/campaign/digital-stamprally/)），电波不稳处GPS+二维码并用；数字版还能抓行为数据（谁集了没兑换、谁中途弃）。

> **御朱印对数字集卡的启示（重点）**：数字卡片无法真"手写独一无二"，须用替代物补：①**记录到访/触发的时间戳与情境**（"你在第X天翻到这张"）；②**限定/季节变体**（同一张卡的不同视觉版本）；③**过程不可预期**（翻开前不知得到什么）；④**把"完成物"做成个人独有的拼合结果**（如ちよ的拼图明信片、Spotify Wrapped式档案）——独一无二从"单卡"转移到"你的整套组合/你的叙事"。

## 四、「个人化产物」链路拆解

**做了"生成属于你的X"的项目**：
- **Spotify Wrapped**：生成年度听歌叙事卡、身份标签（听觉人格、top 0.5%听众、Sound Town地理社群）。
- **ちよ散歩明信片拼图**：集齐拼成一整幅插画（实体个人化完成物）。
- 豆瓣年度报告/Letterboxd/StoryGraph（阅读观影档案，本轮未抓正文，标**(未核实)**——但与Wrapped同属"数据→叙事→分享"链路）。

**为什么 Spotify Wrapped 能刷屏（核心机制，有数据）**（[webtonic](https://www.webtonic.io/blog/spotify-wrapped-marketing-strategy-7-lessons-from-a-viral-campaign)、[NoGood](https://nogood.io/blog/spotify-wrapped-marketing-strategy/)、[jobaaj](https://www.jobaajlearnings.com/casestudies/Spotify-Wrapped-Case-Study-How-User-Data-Became-a-Viral-Marketing-Phenomenon)）：
1. **数据→叙事**（Narrative Bias）：把"你听了2061分钟"改写成"你和XX相处34小时"，统计变关系。
2. **最优区分理论**（Optimal Distinctiveness Theory, Brewer 1991）：同时满足"归属集体大事件"和"彰显独特品味"——既合群又出挑。
3. **身份徽章 + 吹嘴资本**："top 0.5%"、听觉人格给了"可说的话"，不只是"可看的图"。
4. **社交优先设计 + 年末时机 + FOMO**：卡片为Stories而生，赶上年末复盘季，越多人晒越不想缺席。
5. **持续进化**：每年加新功能保持新鲜。

**可分享性数据**：2023年90M+用户分享、2020→2021推文+461%、2025首日200M活跃、年产20亿+社媒曝光——**媒体成本近乎为零的自传播**。

> **对我们的启示**：集卡终点不该只是"集满了"，而应是**一张可分享的、专属于你的产物**（你的故事线组合/你的Lemi档案），把独一无二和传播引擎都建在"完成物"上。

## 五、随机 / 骰子机制评估

**gacha/loot box 的心理与争议**（[Xiao研究](https://rr.peercommunityin.org/articles/rec?id=264)、[loot box法律综述](https://blog.promise.legal/loot-box-laws-game-developers/)、[GamesIndustry 2024](https://www.gamesindustry.biz/loot-box-state-of-play-2024-another-trip-around-the-world-of-regulation)）：
- 上瘾机制：**变比强化**(B.F. Skinner)、near-miss(差一点)、illusion of control、sunk cost、期待时的多巴胺。
- 争议核心是**三要素测试**：consideration(真钱)+chance(随机)+prize(有价值的奖品)。**移除任一要素即通常不构成赌博**。虚拟物若无变现路径("Embedded-Isolated")多数法域不算赌博；一旦有二级市场变现即触发赌博法。
- 监管：**比利时刑事禁止付费开箱**（罚款至€80万，但研究发现禁令基本没被有效执行，82%畅销游戏仍在用随机变现）；**荷兰法院推翻了对EA的处罚**，付费开箱合法；中/韩强制概率公示；英/澳/美有立法讨论。
- 危害证据：loot box支出与问题赌博严重度正相关；UBC 2023研究提示"loot box参与增加首次赌博可能性"。

**随机 vs 可控——何时上瘾、何时恼火**：
- **上瘾**：奖励不可预期（变比）、结果与"努力/付费"挂钩、有near-miss、有稀缺展示。
- **恼火**：随机决定的是"用户真正想要的核心目标"且没有保底时（纯运气墙）。业界对策是 **pity/天井系统**（累计到上限必给），把纯随机变成"随机+保底"。

**我们的关键区分：骰子只控"走多远"不控"得什么"（途经格子都触发，不跳过）**
- 这是**桌游的经典 roll-and-move（掷骰移动）机制**——大富翁、人生游戏、蛇梯棋都是"骰子定步数、路过/落点的格子必然触发事件"。属常识性成熟机制。
- **业界评价（我的分析，非直接引文）**：这个设计**规避了gacha的核心争议与上瘾风险**——因为随机作用于"路径/顺序"而非"是否获得奖品"。用户走完全程必然触发所有途经格，等于**结果确定、只是顺序被随机化**。这更接近"禀赋进度效应+蔡加尼克"的良性驱动，而非loot box式的运气墙。
- **潜在风险**：①若卡片只在"落点格"给而途经格不给，骰子点数就会决定得卡快慢，引入运气差体验；题面说"途经的格子都会触发"，则**没有这个风险，很好**。②随机若完全不影响任何结果，可能显得"骰子是多余装饰"——需确保随机带来节奏/惊喜感（先得哪张、路径体验不同）。③SR彩蛋卡若绑定在特定格，骰子仍可能让人"跳过感"——但题面说不跳过，规避了。

## 六、对 Lemi's Diary 集卡系统的诊断（逐条）

我们的设计：**20格棋盘 + 摇骰子走格 + 7张POI卡(R) + 3张彩蛋卡(SR) + 卡册分母10 + 未获得显示剪影 + 集满解锁SSR碎片(需3条故事线) + 纯线上不要求到场。**

**1. 20格棋盘 + 骰子走格（途经必触发、不跳过）** ✅ **对**
- roll-and-move是成熟桌游机制，且"不跳过"让**结果确定、只随机化顺序**，规避了gacha的运气墙与法律/上瘾争议。随机只提供节奏与惊喜。放心用。
- 小提醒：确保途经格真的都触发发卡/事件，否则骰子会变成"得卡速度的运气差"。

**2. 卡册分母10（7 R + 3 SR）** ✅ **数量合理，但"最优点数"无实证**
- **诚实说明：查不到"几个收集点最合适"的公开实证数字**。てくてくスタンプ明确讲"没有明确的时长/数量标准"，只说"多则回游高但太多会流失"。任何声称"7±2最优"之类的都是我不应编造的。
- 参照系：主题集章拉力多在**8–15点**（ちよ15点、五馆文学巡礼5馆）短期可完成；护照/御朱印(400+/无限)是终生收集。**10张属于"短期可完成"区间，与主题拉力一致，是合理选择**，成就感与不放弃之间平衡尚可。

**3. 稀有度分级 R/SR/SSR** ⚠️ **有效但需防焦虑，且注意与gacha切割**
- 分级本身能制造追逐（收集集合理论、损失厌恶），但**反例存在**：收集疲劳/焦虑真实存在（Zeigarnik的"反刍"副作用、收集疲劳论坛证词）。
- **关键**：我们的SR/SSR若通过"走格/完成故事线"获得而非"付费随机抽"，就**不触碰loot box争议**。务必保持稀有卡的获取路径是"努力/进度"而非"付费概率"。
- 3个稀有档对10张的小卡册够用，别再加档，否则超稀有会变成焦虑源。

**4. 未获得显示剪影** ✅ **有依据（蔡加尼克效应）**
- Zeigarnik 1927原始文献：未完成任务产生心理张力、记忆留存约2倍。剪影=可见的"开放回路"，是**有实证心理学支撑**的正确做法。
- **但要控量**：Syrek等研究显示未完成会引发反刍/焦虑。10个缺口尚可控；若缺口叠加压力，可用"做出完成计划即释压"的思路（如显示"再走X步就能得到它"）。

**5. 集满解锁SSR碎片（需3条故事线）** ✅✅ **很对，且可再强化**
- "集满→解锁下一层"契合**禀赋进度效应**：Nunes & Drèze洗车实验，预填进度让完成率19%→34%。建议：**别让用户从0/10冷启动**，开局就送1–2张/预填一点进度，显著提升坚持率。**切记不要在接近终点才送进度**（会贬低已有努力）。
- 3条故事线 = 分层目标，避免单一长目标的放弃点；符合ちよ"多主题路线"思路。

**6. 纯线上、不要求到场** ⚠️ **最大差异点，需专门补偿**
- 御朱印/护照/geocaching的成就感**核心正是"真实到达"**（"我真去过"）。纯线上抽掉了这根支柱。
- **纯线上下"收集"仍有意义**，但要靠替代物补"真实到达"：
  - **叙事到达**：把"翻到某张卡"包装成"抵达某段故事/某个千代的人生片段"，用narrative transportation替代物理位移（Spotify把"听了X分钟"变"相处X小时"就是此理）。
  - **时间戳/情境独一无二**：记录"你在第几天、什么顺序解锁"，制造类御朱印的"这一份是我的"。
  - **可分享的个人化完成物**：终点给一张"专属于你的Lemi档案/海报/拼图"（学Wrapped+ちよ拼图明信片），把成就感和传播都建在完成物上。
  - **UGC钩子**：像ちよ的Instagram活动那样给一个"值得晒"的产物与话题。

> **放弃点与防流失（综合）**：てくてくスタンプ指出传统"集满才给"是主要流失源→**我们已用"集满解锁SSR"要小心别只有终点奖**，建议加**分档小奖/阶段解锁**（学ちよ 5/10/15档）；开局**预填进度**（禀赋进度效应）；缺口用剪影但控量防焦虑。
