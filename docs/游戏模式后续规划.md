# 后续规划：Lemi's Diary 游戏模式（暂缓）

> **状态：暂缓（parked）。** 本轮方向调整——常规模式全面对标 storymap 优先落地，**游戏模式暂不考虑**。
> 此文档完整保留游戏模式已有设计，作为后续启动时的现成依据，避免二次返工从零设计。
> **重要变更：已删除「昼夜切换模式」**——不再区分昼/夜两阶段，一局为单一时段体验。
> 主需求见 [requirements.md](../requirement/requirements.md)。

## 0. 为什么暂缓

- 现阶段先把「可浏览、可检索、可信」的常规模式（对标 storymap 人物页双栏联动 + 首页 Hub + 搜索）做扎实，这是产品价值与内容可信度的基本盘。
- 游戏模式（大富翁玩法 + 集卡）是"种草/好玩"向的增强层，依赖常规模式的内容与数据先就位，适合作为第二阶段。
- 因此本轮不投入游戏模式实现，仅冻结设计。

## 1. 游戏模式 · 上层导航（世界地图 → 城市 → 故事线 → SSR）

- **功能描述**：在棋盘之上提供「世界地图（城市选择）→ 城市（故事线选择）→ SSR 解锁进度」的导航框架。
- **首期程度（业务规则）**：**仅占位，保留可扩展性**——
  - 导航层界面做出来，但未上线的城市 / 故事线 / SSR 以**剪影 + 锁定占位**呈现，显眼但不可进入。
  - 仅「巴黎 ·《艾米莉在巴黎》」可进入棋盘；其余（巴黎其它 2 条线、其它城市、SSR）均为「待解锁」占位。
  - SSR 位始终显眼锁定，显示解锁进度（如 `1/3`），作为明写的下一步钩子。
- **输入/输出**：用户点击可进入的城市/故事线 → 进入对应棋盘；点击占位项 → 提示「待解锁」，不进入。

### 页面：导航层（占位版）
- **页面用途**：立起收集游戏的空间框架，展示「可玩的」与「待解锁的」。
- **核心元素**：世界地图 / 城市入口、城市内故事线列表、SSR 解锁进度位。
- **用户操作流程**：选可进入的城市/故事线 → 进棋盘；点占位项 → 「待解锁」提示。
- **状态与反馈**：未上线项 = 剪影 + 锁定 + 待解锁标；SSR 位显示 `x/3` 进度。

## 2. 游戏模式 · 核心机制（地图基座 + 遍历所有 POI + 拍立得显影）

- **地图为基座（业务规则 · 强化）**：游戏模式与常规模式**都以真实城市地图为主舞台**，POI 只是地图上的特殊点位。棋盘不是脱离地图的抽象格子，而是**在地图上沿真实街道把 POI 与路途格串成一条路线**；Lemi 棋子在地图上行走。骰子、卡册等作为地图之上的 HUD。
- **大富翁核心玩法**：大富翁棋盘 + 骰子控节奏不跳 POI + 掉卡集卡 + 卡池 R/SR/SSR + 全屏卡册（n/总数 计数、剪影占位、SSR 锁定进度）。核心玩法详见 v2 board-game spec。
- **遍历所有 POI（业务规则）**：骰子只控制"走多远"、不控制"跳过谁"。摇到 N 就沿路线连续走过 N 格，**途经的每个 POI 都触发掉卡、一个不跳过**，保证一条线能完整遍历全部 POI，叙事不断裂。
- **触发点位 = 拍立得显影（业务规则 · 强化）**：落到/途经 POI 触发掉卡时，以**拍立得即时成像**呈现——先在棋子处闪一次快门取景框，再出片：照片从**模糊灰白 → 清晰彩色**显影，白色宽边上以手写体浮现标题与经典台词（无合格引语则留白）。点任意处收入卡册。这是核心的"惊喜感"来源，不用普通弹窗。
- **棋盘规模（业务规则）**：每条故事线的棋盘格数**控制在 5-15 格**（含 POI 格与路途格），按该线 POI 数量与站间距离生成；不固定为 20 格。
  - 排布规则：POI 格按故事线顺序固定，路途格（街头/机会/机位/彩蛋）填充在相邻 POI 之间、按实际距离分配，每两站之间至少 1 格避免两 POI 紧邻。
- **~~昼夜切换~~（已删除）**：不再区分昼/夜两阶段，一局为单一时段体验；原「第 13 格切夜」「昼夜两套配色」「昼夜平滑渐变」设定全部移除。

### 卡池（继承 v2）
- **R**：POI 落格必掉（每 POI 1 张）。
- **SR**：彩蛋格触发（少量）。
- **SSR 碎片**：跑完 1 条线得 1 枚，集齐 3 线合成 SSR。
- **SSR**：集齐 3 线合成，首期挂「待解锁」。
- **卡册页**：全屏，右下角带计数入口（n/总数）；未获得卡剪影 + `?`；SSR 位锁定显示进度 `1/3`。

## 3. 与常规模式的关系（启动时对齐点）

- **共用同一份数据**：游戏模式与常规模式共用三层数据模型（POI / StoryStop / StoryLine / City），差异只在表现层。
- **双模式互切保留上下文**：启动游戏模式时需补：默认进入游戏模式、右上角一键切常规模式、互切保留当前故事线/POI 位置。
- **状态解耦**：常规模式为纯只读，不读写玩家进度/卡册；游戏模式独占玩家进度 localStorage。
- **地图基座一致**：两模式都以真实城市地图为主舞台，可复用常规模式已落地的地图/底图/路线渲染能力。
