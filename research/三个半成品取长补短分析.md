## 1. 半成品一号（我的 Web demo）分析

### 优势
1. **真实地图底座**：MapLibre GL + CARTO 真实街道底图 + 7 个真实经纬度 POI，路线连真实点位，可拖拽/缩放/切矢量影像。这是三者里唯一"真地图"。
2. **真实配图**：每个 POI 挂 Wikimedia 真实照片（花神/铁塔/歌剧院等），非占位色块。
3. **功能覆盖广**（对标 storymap 全链路）：世界地图选城 → 城市 Hub（搜索联想/章节时间轴/城市地图/主题标签四视角）→ 故事线双栏页（时间轴×地图双向联动、自动播放轨迹逐段生长、panTo 克制镜头、四类叙事分段、关联名人名作 tooltip、延伸提问卡、关系图谱、背景知识、导出行程图、全屏、键盘导航、中英双语）。
4. **信息密度高**：每站有序号/古今名/步行时长/四类叙事/名句/机位/实用tips/关联/背景知识——适合"深度查资料"。

### 问题
1. **太重、太满**：一屏塞满信息，是"资料库视角"，缺少三号那种"留白与呼吸"。对"出发前躺着刷"的轻松种草场景不够友好。
2. **Web 宽屏优先**：而真实用户场景（地铁上、景点前）几乎都在手机上。移动端虽做了响应式，但不是 mobile-first 设计。
3. **缺"产品钩子/情绪设计"**：有一堆功能，但没有三号那种"读完才点亮""下回你真站到那儿会想起他"的情绪锚点与收集动机。用户为什么要一站站走下去？动机偏弱。
4. **信息呈现直白**：叙事是"陈述式"（谁在这里做过什么），缺三号"钩子式"文案（先抛一句让你好奇的话）。

## 2. 半成品三号（巴黎云游小程序）分析

### 优势（**产品理念是三者里最强的**）
1. **极致克制的产品哲学**（图例里明写的设计要点）：
   - **「读完才点亮」**：POI 卡片背面的"读过了"按钮，必须正文滚动到底才出现——**把"集卡"挤出去，把"阅读"留下来**。这是一个价值观极清晰的反套路设计。
   - **「低存在感」**：首页只有一句极轻提示"点亮一个地方，听它说一件你还不知道的事"，无"今天带你走…"式说教。
   - **「无底部 Tab」**：活地图独占主屏，旅行日记只作右上角角标。
   - **「隔屏不在场 / 指向未来」**：卡背结尾用"下回你真站到钟楼底下…"，**不假装用户在现场**——诚实地承认这是"出发前种草"，反而更打动人。
2. **文案极出彩**（钩子式，非陈述式）：
   - 圣母院："钟楼上那只大钟，敲了八百年。雨果让一个谁都不愿多看一眼的人，住了进去。"
   - 先贤祠："活着被骂了大半辈子的人，死后被整座城抬了进去。"
   - 孚日广场："写《悲惨世界》的那张桌子，他是站着写的。"
   - —— 每条先抛悬念钩子(hook) → 再给"晚到的事实"(fact) → 结尾指向未来(end)。这套"**hook → fact → end**"三段式比一号的"四类叙事"更有阅读驱动力。
3. **「作品线」这个组织概念极好**：不是"景点集合"，而是"**同一个人的脚步/一部作品的地理**"——雨果的巴黎、天使爱美丽的蒙马特、海明威的左岸。POI 之间有**隐藏的叙事主线**（暗线说明），"你点到了自然会看出来"。这比一号的"故事线=取景地清单"高级。
4. **故事册 + 暗线**：集齐一条线后触发故事册，末尾有"暗线说明"揭示主线逻辑，再用"低存在感"的方式弱提示下一条线。收集动机 + 叙事闭环设计完整。
5. **mobile-first**：真手机场景。

### 问题
1. **地图是假的**：静态手绘地图图片 + 绝对像素定位 POI。不能拖拽/缩放、不贴真实地理、扩展到多城市就崩。这正是一号的强项。
2. **配图是 emoji**：⛪🏛️✍️🌳 占位，没有真实照片。
3. **纯原型、无真实交互深度**：翻卡/滚动/点亮是 demo 级；没有自动播放、没有时间轴、没有搜索、没有多视角浏览。
4. **只有单一叙事路径**：一条"雨果的巴黎"跑通，横向浏览/检索能力缺失。

## 2.5 半成品二号（"旅行——走进一段故事" AI 陪伴原型）分析

> 走查路径：首页（AI 助手 Lemi + 猜你想去地图 + 旅行人格测试 + 与你有缘匹配 + 作品卡）→ 作品详情（《巴黎圣母院》/雨果）→ 名人导游对话 → 旅行日记（收集解锁）→ 我的（成就/人设）。

### 优势（**情感化 / 陪伴感是三者里最强的**）
1. **AI 助手 Lemi 作为主入口**：首页底部常驻"告诉 Lemi 你想去哪…"输入框 + 语音按钮，配"我想去巴黎圣母院""推荐一些小众景点"快捷问句——把"检索/规划"变成**对话式种草**，降低启动门槛。这是一号（功能入口）、三号（地图点亮）都没有的第三种入口范式。
2. **名人扮演"专属导游"（最大亮点）**：从作品详情点"走进《巴黎圣母院》"进入**雨果本人**的对话页（"维克多·雨果 · 巴黎圣母院专属导游"），开场"欢迎来到我的圣母院。抬头看看那些滴水嘴兽…"，可继续追问（"卡西莫多平时住在哪里？"→ 雨果答"他住在南塔楼的钟楼里…"）。**把 storymap 的"时空对话"落成了旅行场景里第一人称、就地、就所见的导游**，代入感极强。
3. **情感化种草组件**：① "测测你的旅行人格"；② "与你有缘 · 匹配度 98%"把一部作品/一个地方包装成"灵魂知己"；③ 顶部随机金句（"灵魂的渴望是命运的先知""人生是旷野"）。这套**玄学/缘分/人格测试**的钩子，正击中"出发前躺着刷"的情绪场景。
4. **作品详情页信息结构清晰**：名人轶事 / 作品简介 / 创作背景 / 同系列作品（横滑）+ 打个招呼 / 收藏 / 换一换 / 👍👎 反馈。与一号"四类叙事"同构，但**更聚焦"人 + 作品"而非"景点资料"**。
5. **收集解锁体系（旅行日记）**：按"📚读万卷书 / ✈️行万里路 / 作品类型 / 必去景点"筛选；每张作品卡带**进度徽章（大师/熟悉）** + "解锁地点"标签（但丁《神曲》→意大利·佛罗伦萨·圣母百花大教堂；雨果作品集→法国·巴黎圣母院/埃菲尔铁塔）+ "继续探索"。**"读作品 → 解锁地理"的收集动机**比三号"读完点亮"更外显、更游戏化。
6. **"我的"页闭环**：旅行成就计数（走进作品 2 / 探索城市 1）、**旅行人设**（"文学漫游者" + 兴趣标签：历史建筑/古典文学/咖啡文化，可编辑）、投喂打赏、反馈、旅行日记入口、为你推荐（但丁·探索佛罗伦萨）。
7. **视觉统一且高级**：复古旧地图海报（米黄/卡其/棕）+ 雾感浅色卡片 + 低饱和绿点缀 + 大圆角，"旅行手账/文学收藏册"气质，与我们巴黎浪漫+简约的方向高度一致。

### 问题
1. **地图是假的**：首页"猜你想去"是静态手绘地图海报（PARIS/VILLE LUMIÈRE）+ 绝对定位的 3 个标签，不能拖拽/缩放、不贴真实地理——和三号同样的硬伤，仍需一号的真地图。
2. **没有真实动线**：全程没有"路线逐段生长/自动播放/时间轴"这类地图叙事动线，地图只是装饰性入口，不是叙事主体。
3. **偏"AI 陪伴轻交互"**：强在对话与种草，弱在"地图叙事"深度；作品详情页大图偏插画、非真实景点照片。
4. **原型态**：交互多为跳转 demo，LLM 对话为预置脚本（真做需后端）。

> **二号给融合方案的三个新增量（一号三号都没有的）**：
> ① **对话式入口（Lemi）** —— 第三种进入方式，降低启动门槛；
> ② **名人第一人称"专属导游"** —— 把"时空对话"落成就地导览，代入感天花板；
> ③ **作品→地理"解锁 + 进度徽章"的游戏化收集** —— 比三号"读完点亮"更外显的收集动机。

## 3. 取长补短：融合方案（打造更好的产品）

**核心判断：一号强在"工程与真实感（骨）"，三号强在"产品理念与克制（魂）"，二号强在"AI 陪伴与情感化种草（温度）"。理想产品 = 三号的魂 + 一号的骨 + 二号的温度。**

### 3.1 定形态：**mobile-first，Web 自适应**
- 采纳二号/三号的手机端优先（真实场景在手机），但用一号的响应式能力让它在 Web 也成立。主屏 = 活地图。

### 3.2 地图：**用一号的真地图，装三号的活地图玩法**
- 底座换成一号的 **MapLibre + CARTO 真实底图 + 真实经纬度**（解决三号"假地图"硬伤）。
- 但**交互采用三号的"点亮"隐喻**：未读 POI 是暗灰点，读完才亮成暖色 + 连线渐次描出。地图不是"展示轨迹"，而是"你亲手点亮的记忆"。

### 3.3 内容：**用三号的"hook→fact→end"三段式，替换一号的"四类叙事"**
- 一号的四类叙事(剧情/轶事/名作/历史)信息全但平铺直叙；三号的"钩子→晚到的事实→指向未来"更有阅读驱动。
- 融合：**正面 = hook 钩子（一句话勾住你）；背面滚动 = fact 深度事实（可含一号的名作/历史/名人多维内容）+ 考据来源（一号的"内容可信"）+ end 指向未来**。
- 保留一号的**真实照片**替换三号的 emoji；保留一号的**机位 tips**（对"真去"有用）。

### 3.4 组织：**用三号的"作品线 + 暗线"，升级一号的"故事线"**
- 一号故事线 = 取景地清单；三号作品线 = 一个人的脚步/一部作品的地理，POI 间有隐藏主线。
- 采纳三号：**故事线要有"暗线叙事"**——走完才在故事册里揭示"这些点为什么是一条线"。这把一号的"共享 POI 跨线关联"从功能升级为**叙事钩子**。

### 3.5 动机：**引入三号的"读完才点亮 + 故事册 + 旅行日记"，但用一号的能力做扎实**
- **读完才点亮**（三号）：正文滚到底才解锁"读过了"，把集卡冲动转化为阅读。
- **故事册**（三号）：集齐一条线触发，含暗线说明。
- **旅行日记**（三号）：点亮数 + 收齐故事册 + 进行中的线，无排行榜无炫耀。
- 一号的**自动播放**可作为"回看模式"——在故事册里一键重走这条线（一号的轨迹生长 + 真实地图）。

### 3.6 视觉：**一号的因城主题 token + 三号的克制留白**
- 保留一号的巴黎浪漫皮肤（香槟金/玫瑰粉/塞纳灰蓝），但采纳三号的**留白与低存在感**——不要一屏塞满，给呼吸感。三号的明信片/手账质感、二号的复古旧地图海报气质，与一号方向一致，可统一到同一套 token。

### 3.7 温度：**吸收二号的"AI 陪伴 + 名人导游 + 游戏化解锁"（低置信度发散）**
- **对话式入口（二号 Lemi）**：主屏之外提供"告诉 Lemi 你想去哪…"的对话入口作为**第三种进入方式**，把检索/规划变成种草对话；纯静态版可先做预设问句 + 预置回答，后端接入后再真做 LLM。
- **名人第一人称"专属导游"（二号最大亮点）**：把 storymap 的"时空对话"落成**就地导览**——每条故事线的主角（雨果/艾米莉/海明威）作为"专属导游"第一人称讲解、可追问。这与三号"hook→fact→end"内容范式互补：**hook→fact→end 是独白，名人导游是可交互的对白**。静态版给每站预置 2–3 组问答。
- **游戏化解锁 + 进度徽章（二号）**：把三号"读完才点亮"升级为"**读作品/走完一站 → 解锁地理 → 进度徽章（熟悉/大师）**"，收集动机更外显；仍守三号"无排行榜无炫耀"的底线。
- **情感化种草（二号，谨慎用）**：旅行人格测试 / "与你有缘 匹配度" / 顶部金句，作为**轻量点缀**吸收——能击中"躺着刷"的情绪场景，但别喧宾夺主、别做成玄学营销，与三号"低存在感"平衡。

## 5. 一句话结论

- **一号**：真地图真照片、功能全，但太重、缺情绪动机 —— 是**好骨架（骨）**。
